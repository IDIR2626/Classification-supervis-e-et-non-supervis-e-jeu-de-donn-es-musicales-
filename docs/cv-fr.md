# Présenter le projet sur un CV

**Analyse de popularité musicale — Python, pandas, scikit-learn**

Analyse de 4 073 titres : exploration des données, comparaison d'arbres et de k-NN par validation croisée, traitement du déséquilibre des classes et clustering k-means. Organisation d'un pipeline reproductible, de graphiques de résultats et de tests sur le prétraitement.

Points à pouvoir expliquer en entretien :

- Pourquoi 63 % d'accuracy peuvent cacher l'échec sur les classes rares.
- Pourquoi les copies de sur-échantillonnage doivent rester dans l'apprentissage.
- Pourquoi le scaler est appris uniquement sur l'apprentissage.
- Pourquoi trois plis sont utilisés avec trois exemples de la classe rare dans l'apprentissage.
- Pourquoi un cluster n'est pas un niveau de popularité.
- Ce que mesurent la silhouette et Rand, et les limites des résultats.

Ne pas annoncer une amélioration globale de précision : le candidat reste sous la baseline majoritaire en accuracy. Les performances sont celles d'une expérimentation, pas d'un service déployé.
